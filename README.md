# Timeline Tracker

Piece together where everyone was over a single day, detective style. Upload a map image, mark named places on it, and give each actor a list of timed activities at those places. The case board shows the map with a time scrubber, everyone's paths and whereabouts, and a timeline chart that flags unaccounted-for time.

Everything is saved in the browser with IndexedDB.

Live at https://blakesteel.com/timeline-tracker/

```sh
npm install
npm run dev     # local dev server
npm run deploy  # build and publish to the gh-pages branch
```
